## 必须提醒成员 A 和 B 的源码行为

- 作者 `BertForSequenceClassification.forward()` 默认调用 `bert_kl()`，不是普通单前向 Baseline。
- 作者同一类中已经提供 `bert_cross_entropy()` 单前向路径。后续 A 的 Baseline 要明确接入普通路径；不能直接把作者默认脚本当成 Baseline。
- `bert_kl()` 内部执行两次 BERT 前向，累加两个默认 batch-mean 的 CE；两个方向的 KL 采用 `.sum()` 后组合。
- 源码中的局部变量 `alpha = 1.0` 乘在 CE 上，KL 的乘数另行写在 `loss += 0.5 * (kl_loss + reverse_kl_loss) / 2.` 中。不能只改那个名为 alpha 的局部变量，就声称完成了 KL 系数消融。
- 作者默认 forward 在评价时也会进入双前向路径。后续正式评价逻辑应统一设计并记录，避免成本统计和训练损失口径混淆。
- 后续 B 的 α 参数化、损失归一化和 α=0 检查需基于这份源码进行，并记录差异；第二步没有代替 B 完成这些实验。

正式 Baseline / R-Drop 训练入口及损失协议将在后续步骤统一确定。现阶段的源代码兼容检查不代表实验协议已全部实现。

## 依赖选择

- 复用已验证的 PyTorch 2.1.2+cu118 和 CUDA 11.8。
- 作者 Transformers 4.6.0.dev0 从本地源码可编辑安装，不从 PyPI 安装普通 Transformers。
- Tokenizers 0.13.3、Datasets 2.19.2、Hugging Face Hub 0.23.5。
- NumPy 1.26.4、PyArrow 16.1.0、Pandas 2.2.2、scikit-learn 1.4.2、SciPy 1.13.1。
- 所有 44 个直接/间接依赖（含安装工具）固定在 `requirements-step2.lock` 中，并附下载 wheel 的 SHA256。
- 当前作者 Trainer 不依赖 Accelerate，本项目评价可直接使用 scikit-learn；本步没有为了凑包清单安装 Accelerate、Evaluate 或 Safetensors。后续预训练权重加载按作者代码支持的格式设计。

wheel 包来自清华镜像，另用 PyPI 官方元数据核验。完整离线安装包面向 Linux x86_64 / CPython 3.10，不能在 Windows 本机或 Python 3.12 中直接安装这些二进制 wheel。
